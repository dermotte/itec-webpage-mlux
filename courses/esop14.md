# Einführung in die strukturierte und objektbasierte Programmierung WS 2014/2015

Einführung in die strukturierte und objektbasierte Programmierung (kurz ESOP) behandelt folgende Themen:

* Allgemeine Einführung und Grundlagen der Programmierung
* Einführung in Java
* Arrays
* Unterprogramme
* Klassen
* Geheimnisprinzip
* Interfaces
* Abgeleitete Klassen
* Ausnahmebehandlung
* Aggregation
* Namensräume
* Ein- und Ausgabe
* Collections
* Rekursion
* Threading
* JavaScript
